### Régimen de aprobación

- **Alumnos de Maestría**: Para promocionar (sin necesidad de rendir final) se deberá aprobar el prefinal con nota mayor a cierto puntaje a determinar y además aprobar el trabajo práctico. En caso de no aprobar el prefinal, se puede recuperar pero se pierde la posibilidad de promocionar, es decir, que se debe aprobar luego el examen final.
- **Alumnos de Licenciatura y Doctorado**: Se deberá aprobar el prefinal o su recuperatorio, aprobar el trabajo práctico y rendir el examen final.
